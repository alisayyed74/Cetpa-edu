# 📘 Cetpa-edu – ReactJS Educational Website

Cetpa-edu is a modern and responsive educational website built with **ReactJS**.  
It serves as a clean and customizable template for training institutes, coaching centers, and e-learning platforms.  

---

## 🚀 Features
- Responsive sticky navbar with smooth scrolling  
- Hero banner with call-to-action  
- Programs showcase section  
- About & Company sections  
- Student testimonials  
- Contact form for queries  
- Popup video player  
- Professional footer  

---

## 🛠️ Tech Stack
- ReactJS  
- JavaScript (ES6+)  
- HTML5, CSS3  
- React Hooks (useState, useEffect)  
- React-Scroll for smooth navigation
